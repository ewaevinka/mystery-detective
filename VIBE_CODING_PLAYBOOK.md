# 🎀 The Vibe Coder's Playbook: Mystery Runway & Detective Atelier

Welcome, Game Designer! 🌟  
You are the **Lead Creative Director** of your own fashion-detective game: **Mystery Runway & Detective Atelier**!

You don't need to memorize complicated computer code. You use **Vibe Coding**: you describe what you want in plain English, and your AI assistant (**Claude Code**) writes the code for you!

---

## 🚀 1. How to Launch Your Game & Start Vibe Coding

### Step 1: Open Terminal on your Mac
1. Press `Cmd + Space` on your keyboard.
2. Type **Terminal** and press `Enter`.

### Step 2: Open your project folder
Type this command and press `Enter`:
```bash
cd ~/Documents/Projects/detective_fashion
```

### Step 3: Run your local game preview
Type this command:
```bash
python3 -m http.server 8888
```
Now open Safari or Chrome and visit:  
👉 **[http://localhost:8888](http://localhost:8888)**  
You will see your game running live!

### Step 4: Start Claude Code!
Open a second Terminal tab (`Cmd + T`) and type:
```bash
claude
```
Claude Code will wake up, read your project rules, and say hello!

## 🎨 2. Ready-to-Use Vibe Coding Prompts (Just Copy & Paste!)

Whenever you want to add something new to your game, just copy one of these ideas and paste it into Claude Code:

### 👗 Prompt 1: Add a New Guest to the Ballroom
> *"Claude, can you add a new character in the Grand Ballroom called 'Lord Sterling the Diamond Collector'? When I click 'Talk', he should say: 'Excuse me! Have you seen anyone drop golden glitter by the stairs?'"*

### 🔍 Prompt 2: Add Another Secret Clue in the Ballroom
> *"Claude, can you add another clue to find on the ballroom floor or by the tables? Like a 'Dropped Golden Cufflink' that we can inspect with the magnifying glass!"*

### ✨ Prompt 3: Make the Teleport Button Even Sparklier
> *"Claude, can you add more floating gems and swirling rainbow colors to the Pretty Teleport Button?"*

### 👑 Prompt 4: Add a New Outfit to the Atelier
> *"Claude, I want to add a new outfit to the wardrobe! Let's add a 'Glittering Starry Ballerina Dress' under the dresses/bottoms category. It should be pastel lavender with silver sparkles and give +40 Glamour points!"*

### 🔍 Prompt 2: Add a Brand-New Mystery Case
> *"Claude, let's create a new mystery case in Case Files called 'The Case of the Scented Secret'. A famous pop star's perfume bottle was stolen backstage during rehearsal. Can you add 3 new clues and 3 new suspects, including one who is guilty?"*

### 👑 Prompt 3: Add New Hairstyle & Accessories
> *"Claude, can you add a new hairstyle option: 'Twin Buns with Butterfly Clips', and a new accessory: 'Diamond Detective Magnifying Brooch'?"*

### 📸 Prompt 4: Add a "Save Runway Photo" Button
> *"Claude, when I finish walking the runway, can you add a button called 'Save Photo' that downloads a picture or screenshot of my model's outfit so I can share it with friends?"*

### 🎶 Prompt 5: Add a Background Runway Music Toggle
> *"Claude, can you add a chic runway catwalk background beat using the Web Audio API with a toggle button to turn the music on and off?"*

### 🌈 Prompt 6: Add Color Customization Sliders
> *"Claude, can you add a color picker button in the Atelier so I can dye any coat or dress my favorite custom color?"*

### 🏆 Prompt 7: Add Detective Rank Badges
> *"Claude, when I solve more cases and earn stars, can my detective rank level up? For example: Junior Sleuth -> Runway Detective -> Royal Haute Couture Inspector!"*

### 💬 Prompt 8: Add Suspect Interrogation Dialogues
> *"Claude, when I click on a suspect in Case Files, can a cute pop-up chat bubble appear where I can ask them questions about where they were during the runway show?"*

---

## 💡 The 3 Golden Rules of Vibe Coding

1. **One Idea at a Time:** Don't ask for 10 giant things in one prompt. Ask for one dress, one case, or one button at a time so it's easy to test!
2. **Refresh & Test Often:** After Claude makes a change, go to your browser tab (`http://localhost:8888`) and hit `Cmd + R` (Refresh) to see your new feature in action.
3. **If Something Breaks, Don't Panic!** Just tell Claude:  
   *"Claude, the dress button isn't clicking. Can you check what happened and fix it?"* — Claude will fix it right away!
